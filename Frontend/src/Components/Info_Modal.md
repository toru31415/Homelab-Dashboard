# Info_Modal.jsx
_Homelab-Dashboard/Frontend/src/Components/Info_Modal.jsx_

## Zusammenfassung
Die Datei ``Info_Modal.jsx`` ist das Info PopUp für ein einzelnes Objekt/node und in React erstellt.

## Details
| Name | Beschreibung |
| - | -
| Rednern vom Modal | Overlay/Popup anzeigen und die Varianten bieten, wie man es schliessen kann.
| Header | Icon und Namen anzeigen
| Body | Anzeigen von... Grosses Symbol/Icon // Status Icon // Optionalen Beschrieb // Details wie IP, Hostname, CPU,... // URL wenn hinterlegt
| Footer | Anzeigen vom "Schliessen" Knopf
